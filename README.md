# EducaSwift Samples

Welcome to the **EducaSwift Samples** repository! 🚀  
This repository contains all the SwiftUI examples and projects featured on [EducaSwift](https://educaswift.com) — your go-to platform for mastering SwiftUI, from beginner to expert.

## About EducaSwift
[EducaSwift](https://educaswift.com) is a dedicated SwiftUI learning platform designed to help iOS developers enhance their skills through practical tutorials, examples, and best practices. Whether you're starting your journey or refining your expertise, EducaSwift has something for everyone.

---

## Repository Overview
This repository includes various SwiftUI code samples aligned with the tutorials and articles on the EducaSwift website. Each folder corresponds to a specific topic or tutorial.

### Example Projects
- **Navigation Samples**  
  Explore navigation patterns, including Tree-Based and Stack-Based navigation using The Composable Architecture (TCA).
  
- **Core Data Integration**  
  Learn how to integrate Core Data into your SwiftUI projects effectively.

- **Animations in SwiftUI**  
  Discover how to create smooth and interactive animations.

- **State Management**  
  Understand how to manage state with tools like `@State`, `@Binding`, and `@EnvironmentObject`.

---

## How to Use This Repository

1. Clone the repository to your local machine:
   ```bash
   git clone https://github.com/EducaSwift/educaswift-samples.git
   ```

2. Open the `.xcodeproj` or `.xcworkspace` file of the example you want to explore in Xcode.

3. Run the project on your simulator or device:
   - Ensure you have the latest version of Xcode installed.
   - Select a simulator or connected device, then click the "Run" button.

4. Follow along with the corresponding tutorial on [EducaSwift](https://educaswift.com).
